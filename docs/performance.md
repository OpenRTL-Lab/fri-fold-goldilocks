# 性能指标

[English](performance.en.md)

单lane、32768点对配置在理想接口下实测任务延迟32819周期、任务间隔32820周期、连续吞吐率0.998415600点对/周期；两条最主要的模乘流水线各有99.902498%的周期包含有效计算，以下给出可复现的定义、窗口及计数。

## 测试方法

执行 [快速复现](reproduction.md)中的完整验证，使用16项正常任务，每项32768点对，输入持续供数、输出与完成通知持续可接受。性能不引入外部带宽、访问延迟或共享端口限制。协议模式独立验证背压，不混入性能数据。

记录上升沿握手的周期编号：任务接受为A，首/末输入为F/I，首/末输出为O₀/O，完成通知接受为C。任务延迟 `L=C−A`；单任务模式单独复核同一口径。连续任务间隔 `T=C_next−C`，吞吐率用实际多个完成间隔测量，不以流水线深度代替。

排除首尾批次，使用完成标签2到13的窗口 `(C₂,C₁₃]`：11个任务间隔，361020周期，完成360448点对。任务吞吐率为 `11/361020`，点对吞吐率为 `360448/361020`。

## 延迟与吞吐率

| 指标 | 周期/周期归一化结果 | 按500 MHz换算 |
| --- | ---: | ---: |
| 单任务延迟C−A，32768点对 | 32819周期 | 65.638 µs |
| 连续任务完成间隔 | 32820周期 | 65.640 µs |
| 首输出距首输入O₀−F | 50周期 | 100 ns |
| 末输出距任务接受O−A | 32818周期 | 65.636 µs |
| 连续任务吞吐率 | 0.000030469226任务/周期 | 15234.613任务/s |
| 连续点对吞吐率 | 0.998415600点对/周期 | 499.207800百万点对/s |
| 活动流点对发射间隔 | 1周期/点对 | 每2 ns发射1点对 |

16项理想任务的最小与最大延迟均为32819周期；隔离单任务结果相同。500 MHz列是周期测量按所述频率换算的结果，不是板级或硅后实测，综合频率依据见 [综合结果](synthesis-summary.md)。这里 M 是任务实际声明的点对数，lanes 是生成时固定的每拍点对槽数。理想接口下，M 可被 lanes 整除且各拍全部有效时，`L=M/lanes+51`、`T=M/lanes+52`；公式用实际任务长度，不自动取 maxPairs 容量上限。复测最小lane1/M8得到59/60周期，lane2/M64得到83/84周期（分别为延迟/间隔）。

点对流水线可以同时容纳不同点对，但控制层同时只执行一个任务。因此小任务与大任务的吞吐率分别由实测任务间隔决定；不能把50周期的点对延迟当成50周期的发射间隔。

## 计算单元忙率

忙率使用真实功能 `valid`，不是电路翻转率或功耗。逐级忙率为该级处理有效点对的周期数/窗口周期数；流水线占用率为至少有一级有效的周期数/窗口周期数。两个数分别表示有效产出负载与整条流水线是否空闲。

| 单元 | 数量 | 级数 | 每级有效周期 / 空闲周期 | 整条非空周期 / 全空周期 | 每级忙率 | 流水线占用率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 第一模乘 | 1 | 21 | 360448 / 572 | 360668 / 352 | 99.841560% | 99.902498% |
| 第二模乘 | 1 | 21 | 360448 / 572 | 360668 / 352 | 99.841560% | 99.902498% |
| 半和与半差 | 各1 | 各10 | 360448 / 572 | 360547 / 473 | 99.841560% | 99.868982% |
| 最终模加 | 1 | 5 | 360448 / 572 | 360492 / 528 | 99.841560% | 99.853748% |

半和/半差共用有效标记，因此表中计数是各实例的计数，不把两个实例相加。每个模乘由16个部分积乘法单元和压缩/约减结构组成；其21个功能级各计数一致。两个模乘单元的综合面积合计约51.80%，面积定义见 [综合结果](synthesis-summary.md)。稳定供数片段的发射忙率为100%，上表保留真实任务切换开销。

## 结果文件与校验

`results.json` 中保存全部任务握手周期、逐级计数和孤立任务结果；脚本验证固定间隔、每级有效次数、填充/排空长度以及原始日志计算结果。提供SV与重新生成SV分别运行全部八种模式，并比较完整测试和性能数据。
